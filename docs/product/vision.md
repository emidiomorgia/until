# Product vision

## Purpose

`until` is a web application for managing deadlines. It aims to make deadlines quick to understand and track through a clear, responsive HTML5 React SPA/PWA.

## Product direction

- Provide a clear, accessible web-first deadline experience.
- Keep the interaction fast and readable across supported browsers and devices.
- Offer an installable PWA experience where it improves access to deadline information.
- Keep frontend, Java backend, and shared contracts coherent within the monorepo.
- Leave room for future microservices without requiring them during the foundation phase.
- Evolve the product incrementally through prepared, Human-approved GitHub Issues.

## Current maturity

The project is in its foundation phase. The TypeScript/React frontend and Java backend direction are established, while the deadline product behavior is not implemented yet. This document describes direction, not an approval to implement unplanned features.

## Out of scope for the foundation phase

- Defining an external data provider or API contract without task refinement and Human approval.
- Promising offline data or historical records without a prepared task.
- Splitting the system into microservices before modular monorepo boundaries and operational needs are understood.
