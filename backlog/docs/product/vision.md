# Product vision

## Purpose

`until` is a web application for weather forecasts. It aims to make current and forecast weather information quick to consult through a clear, responsive HTML5 React SPA/PWA.

## Product direction

- Provide a clear, accessible web-first weather experience.
- Keep the interaction fast and readable across supported browsers and devices.
- Offer an installable PWA experience where it improves access to weather information.
- Keep frontend, Java backend, and shared contracts coherent within the monorepo.
- Leave room for future microservices without requiring them during the foundation phase.
- Evolve the product incrementally through prepared, Human-approved Backlog.md tasks.

## Current maturity

The project is in its foundation phase. The TypeScript/React frontend and Java backend direction are established, while the weather product behavior is not implemented yet. This document describes direction, not an approval to implement unplanned features.

## Out of scope for the foundation phase

- Defining a weather provider or API contract without task refinement and Human approval.
- Promising offline forecasts or historical data.
- Splitting the system into microservices before modular monorepo boundaries and operational needs are understood.
