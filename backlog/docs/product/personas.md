# Personas

## Web user

Wants current and forecast weather information in a clear browser experience. Values fast navigation, readable summaries, responsive layouts, and accessible interaction across desktop and mobile devices.

## Mobile or intermittently connected user

Uses a phone or an intermittently connected network. Values an installable PWA, efficient loading, graceful failures, and honest indication of stale or unavailable data.

## Maintainer

Needs a maintainable TypeScript and Java monorepo that can evolve safely. Values explicit specifications, focused tasks, automated verification, and documentation that stays aligned with the implementation.

## Notes

These personas guide refinement and review. They do not replace a task-specific SPEC or acceptance criteria.
